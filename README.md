# DeFiState

DeFiState provides a stateful financial platform engine that leverages auto-scaling and fault-tolerant architecture.

The key benefits of using DeFiState include:

- DeFiState provides a stateful financial
- platform engine that leverages auto-scaling
- and fault-tolerant architecture

## Key Features

- DeFiState provides a stateful financial
- platform engine that leverages auto-scaling
- and fault-tolerant architecture

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/DeFiState.git`
2. `cd DeFiState`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DeFiState, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
